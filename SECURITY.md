# Security

devhub-bridge can type into your terminals, so a hole in it is a hole
in the machine it runs on. The README's Security section describes who
the bridge lets in.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new)
(Security → Report a vulnerability), not in a public issue. Include
what an attacker needs (network position, a page you visit, a file an
agent opens, …) and what they get.
